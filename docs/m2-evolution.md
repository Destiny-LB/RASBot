# M2：生成能力的最小自主演进

工作台入口：“自主演进”页中的“自主演进 · 生成能力”。服务端每 5 秒推进一次；页面不负责调度。关闭页面不停止任务，重启平台后从 SQLite 记录继续观察已有会话。

## 本轮工作流

1. 选择已结束的精度任务作为诊断证据，选择 2–3 个不同的评测算子。至少一个算子不得出现在诊断证据中。
2. 固定基线、模型、任务资产、Skill、准备工具和生成评价器摘要。
3. OpenCode 以结构化工具结果和状态轨迹为输入，返回诊断、完整候选执行提示词和元评价建议。不得调用工具；发现调用即终止提案。
4. 平台保存不可变候选版本及父版本，自动创建每个算子的基线/候选任务。每个任务使用独立工作区和会话，使用相同模型与正式 max_cases。
5. 复用 M1 独立生成门禁。每个会话最多 30 分钟，本轮最多一次提案和六个生成会话，不自动修复或重试。
6. 候选全通过且通过数严格高于基线才晋升。平局或退化保留基线；执行环境异常、人工追加消息或固定资产变化使结果无法支持晋升。
7. 晋升修改 precision 域后续新任务的默认版本，历史任务继续绑定其原版本。

## 评价与元评价的区别

`generation-gate-v1` 只评价生成合规性：正式数量、输入规格去重、必需报告、受保护资产和原准备工具的无警告通过。它不证明数值覆盖质量、缺陷检出率或硬件可靠性。

提案中的 `meta_evaluation` 是评价器缺陷和改进建议，单独展示，不作为候选版本的可执行指令，也不会改写本轮评分规则。评价器候选的独立校准、影子评测和自动晋升仍是后续工作。

这是一轮有界自主实验，不是无限递归搜索。当前每算子每版本只有一次运行，不能推断统计显著性；时间/费用等指标还没有进入晋升函数。没有硬件任务、SDC 或容错执行接入。

## 证据与状态

- `evolution_runs`：固定协议、模型、证据、候选、试验任务、判定与时间线。
- `versions`：内容寻址的候选与父版本。
- `champions`：各域采用版本。
- 每个试验任务沿用 M1 的指令快照、会话轨迹、验证日志和产物摘要。
- `.rasbot/m2-run.json`：本次实测轮次 ID。

POST `/api/evolution/start` 接收 `source_ids`、`slugs` 和可选显式 `model`；未提供模型时必须已在平台设置中选择具体模型。GET `/api/evolution` 查看状态，POST `/api/evolution/cancel` 停止本轮，POST `/api/evolution/tick` 单步推进。所有 POST 沿用平台请求令牌。

网络不确定时，不自动重复提交提案。`proposal_starting`/`proposal_unknown` 保留会话与错误，需核查后停止该轮；当前未提供自动重放。权限请求保留在任务 OpenCode 面板中，不自动授予权限。

提示词与摘要检查不是操作系统隔离。当前仍依赖 OpenCode 的工具权限；若要运行不受信任的候选代码，必须先增加沙箱与只读验证服务。本阶段只生成提示词 overlay，不允许模型修改平台或验证工具。

回滚 API：POST `/api/evolution/rollback`，传入已晋升轮次的 `id`。只有当前采用版本仍是该轮候选时才允许回滚；历史任务不改绑。

本次验证中，初始轮次因提案输入混入旧规划元数据而主动停止，记录保留。修复后仅传入实际生效的 execution overlay，并固定演进控制器本身的摘要。正式验收轮次为 `4e05acd18c6b4acfb1a19d09e1facf94`；实际结果以持久化记录为准，本文不预先声明改进成功。

门禁边界：必需报告目前只检查存在与非空，原工具承担其支持的 schema/覆盖一致性检查；尚未自动评价报告语义、用例设计价值或全部 Skill 方法约束。即使晋升，也只能声明在本轮固定生成门禁下改善，不能视为全任务契约或精度能力的全面证明。

实际恢复检查：Expm1 候选运行期间重启 RASBot 服务，后台恢复同一任务与 OpenCode 会话，panel.user_message 记录仍只有一次，未重放执行请求。该任务随后通过独立生成校验。

Harness 版本页为只读审计入口：显示父子谱系、执行提示词 overlay 的逐行差异、完整版本内容、关联自主评测及当前采用状态。手动候选登记表单与 POST /api/candidates 已移除；版本继续由自主演进流程写入。历史版本和评测数据保留。

语言规范：后续演进提案的诊断、候选执行指令、元评价建议及生成任务的解释/报告统一要求简体中文；代码标识、路径、命令、JSON 键名等机器可读内容保留原文。界面固定中文，移除语言切换及旧浏览器语言偏好的读取。历史版本与证据原文不改写。

自动任务选择：页面加载时推荐诊断依据和评测范围，不调用模型、不启动实验。优先最近失败运行并配合同算子成功样本；无失败时选最近成功运行。排除未实际运行的取消记录，另选未参与本轮诊断的算子为保留任务（不保证它从未在历史实验中出现）。用户可通过任务选择控件调整。固定任务池首次从具备 prompt 的任务目录建立，存于 `.rasbot/evaluation-pool.json`；新任务不会静默加入。每轮保存选择策略、池内容、是否调整和选定任务。本轮演进预算支持 30/60/120 分钟，默认 60 分钟。提案分配 min(300, 总秒数的 10%)，预留总预算的 10% 用于准备和验证，其余均分给所有对照执行；基线与候选预算相同，启动后随评价器固定。整轮从实际开始推进计时，包含准备、等待与验证。预算耗尽停止新增执行，确认引擎停止并保存轨迹后记为 inconclusive，不据此晋升。后台每 5 秒检查；正在进行的本地准备/验证及网络请求完成后再次检查，因此这是调度预算，停止确认可能超出所选时长，不是操作系统级硬截止。旧历史记录保留原始单会话策略。
