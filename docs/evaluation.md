# 评价与轨迹分析

## 轨迹诊断与关联检查

新增 `GET /api/analysis?task_id=...`，只读分析已有产物，不调用模型、不重跑任务、不修改历史分数。演进历史的每个任务提供诊断入口。

`traceability-shadow-v1` 检查生成规则与覆盖账本的双向关联、悬空用例、重复 ID、未评估条目、适用但无用例的条目、跳过却关联用例、缺失意图及引用格式。返回产物哈希、问题总数和最多 100 条问题。它是独立观察指标，尚未进入晋升条件。

轨迹摘要提供验证失败原因、结构化工具失败次数和已结束状态的驻留时间。驻留时间包含轮询与等待；最耗时状态只是瓶颈线索，不是模型推断的根因。无轨迹时明确标记不可用。

校准采用干净合成样本和八类人工破坏样本，验证结构问题的检出能力。它不是已知硬件缺陷集，也不能证明数值覆盖质量。测试专门保留一个“引用一致但边界语义错误”的样本，说明本检查无法识别该问题。

后续仍需：建立算子领域判定器及独立保留集，验证真实缺陷检出能力；据此校准新评分规则；再启动真实模型对照。SDC/容错执行器和多轮探索不在本阶段实现范围内。不得将本观察结果追溯改写为历史轮次的新分数。

## 输入多样性与离线审计

- `quality.py`：声明式输入规格去重、形状与 dtype 组合数。只忽略 id/意图/引用文本，保留其他字段，避免仅改描述掩盖重复。
- `/api/analysis` 结果新增 input_diversity，原 traceability-shadow-v1 规则不变。
- `evaluation_audit.py`：只读数据库，快照平台 Python 源码、Harness 版本、采用记录与演进结论，复制生成输入和覆盖账本；校对产物摘要。输出目录必须是新目录，不覆盖历史审计。
- 校准：编号/叙述变化、键顺序、形状/dtype 差异、其他语义字段、非法输入及指标无法检测的语义反例。与原有引用关联破坏样本一起运行。

运行：`python -m rasbot.evaluation_audit --output .rasbot/reports/<unique-name>`。

2026-11-10 已对五个 generated 任务执行离线观察：每个 1000 条，重复规格为 0，引用问题为 0，suite/ATK 摘要与历史记录一致。报告在本机 `.rasbot/reports/evaluation-upgrade-20261110/`。

## 解释边界

本批观察仍无法区分基线与候选的真实数值测试能力。不能因输入种类更多就判为更优，也不能把重复规格直接判为无效：重复采样可能有实验价值。指标不进入晋升政策，不修改既有 rejected 结果。

这是结构指标校准，不是独立真实缺陷保留集。快照不等于完整环境冻结：模型服务、完整工具依赖、系统与硬件仍需独立记录。下一步需为选定算子制定可复核的领域判定依据，再引入真实实验评价。



晋升政策统一见 [自主演进](evolution.md)，此处的影子指标不参与晋升。

## 从真实运行中提炼的内部规则

历史运行仅供开发分析，不提供历史目录导入、上传、扫描或注册接口；不把历史数据写入平台数据库或经验库，不把旧硬件成绩用于新候选晋升。测试使用合成的最小样例。

`evidence.py` 将生成验收、文件完整性、硬件比较与根因确认分开。现有精度 Harness 的硬件状态始终为 `not_evaluated`；工作区中出现报告或人为填写成功字段不会提升它。`GET /api/analysis` 在已有任务诊断中返回这一语义，不增加新端点。

真实运行暴露了“验收后产物变化”的风险。因此正式评测读取任务结果时，重新校验该任务工作区固定路径下的规则文件和 ATK 输入哈希。已记录摘要但文件缺失或被改写，会使该次执行不可比较，不能促成晋升。没有摘要的旧记录标记 `not_recorded`，兼容原生成评价但绝不标记证据已验证。原有历史终态分数不重算。

内部纯函数 `comparison` 为将来的执行适配器规定逐例语义，不读取任何文件，不接受 LLM 报告作为可信来源：

- 只有执行错误、没有有效比较时是 BLOCKED，不能称为精度失败。
- 有可信比较且全部通过时可以是 PASS，同时记录执行错误和未比较的覆盖缺口。
- accuracy_false 保留为观察到的 FAULT，不推导为已确认内核缺陷数量。
- 比较可信性未知或为否时，最终为 BLOCKED，但保留原始观察状态和计数。
- 重复 case ID、无效分类和不完整分母不能生成有效结论。
- 精度失败率分母只取实际比较案例；没有比较时返回空值，不显示 0% 失败或 100% 通过。

硬件尚未接入，该纯函数不参与当前生成阶段评分；根因确认仍需独立证据，不从报告状态或失败数量自动推导。
